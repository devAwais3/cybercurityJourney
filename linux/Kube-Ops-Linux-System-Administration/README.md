# Kube-Ops Linux System Administration

## About This Track

This repository documents my hands-on learning journey through the Linux System Administration track offered by Kube-Ops Academy.

The track consists of 37 practical lessons covering Linux system administration concepts, commands, configurations and real-world exercises.

My goal is to strengthen my Linux administration skills through practical implementation and maintain organized technical documentation of my learning.

## Learning Objectives

- Strengthen Linux system administration skills.
- Practise user, group and permission management.
- Understand processes, services and system monitoring.
- Develop practical troubleshooting skills.
- Build a strong foundation for cybersecurity and SOC operations.
