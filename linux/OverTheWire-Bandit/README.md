# OverTheWire Bandit

## About This Wargame

This repository documents my hands-on learning journey through the **Bandit wargame**, provided by OverTheWire.

Bandit is designed for beginners and introduces essential Linux command-line skills through practical challenges. Each level presents a task that must be solved to retrieve the password required to access the next level.

My goal is to strengthen my Linux fundamentals, improve command-line problem-solving skills, and develop practical knowledge useful for cybersecurity and SOC operations.

## Learning Objectives

- Understand Linux command-line fundamentals.
- Practise file and directory navigation.
- Learn to search, read, and manipulate files.
- Understand Linux permissions and ownership.
- Work with SSH and remote system access.
- Explore useful Linux commands and utilities.
- Develop problem-solving and troubleshooting skills.

## Documentation Structure

Each level has its own directory containing:

- `README.md` – Level objective, approach, commands, explanations, and key takeaways.
- `assets/` – Screenshots and supporting evidence from the practical exercise.

Example:

```text
Bandit/
├── README.md

```

## Accessing the Wargame

Bandit is accessed remotely through SSH using a Linux machine or virtual machine.

- **Host:** `bandit.labs.overthewire.org`
- **Port:** `2220`
- **Protocol:** SSH
- **Operating System used:** Kali GNU/Linux 2026.3 (VM)

Each level provides the credentials needed to access the next level.
