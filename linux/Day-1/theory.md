# HISTORY OF LINUX

## What is Linux?
Linux is a family of open-source Unix-like operating systems based on tthe linux kernal by linus torvlads. Linux is typically packaged in a linux distribution.
Linux was originally developed for personal computers based on the Intel x86 architecture. That's the same architecture that we use for windows machines, for macintosh machines today.
It was then ported to many other platforms. These are typically servers that are out today in the internet, in the cloud today.
   - Android,which is google smartphone, which has atleast half of the smartphone market, uses linux.
   - Chromebooks, which had become very popular again from google. They have the chromeOS that uses linux.
   - Many embedded systems also run linux.
   - About 90% of the cloud infrastructure is powered by linux.

## How is linux different?
Linux has manu advantages over other OS's including:
   - Open Source (We are able to see the source code, make changes and share with other people. That's not true of other OS's)
   - Community Support (Because its open source so lots of people can provide support. We are not locked into one vendor for support.)
   - Support for Older Hardware (Other OS's try to get you to upgrade your hardware all the time which becomes expensive. Linux actually works on older machines.)

## Linux Precursors

### UNIX PROJECT
1. The Unix operating system was conceived and implemented in 1969, at AT&T's Bell Labs.
   - Bell Labs was AT&T's research lab. In 1969, engineers there built Unix, one of the first major operating systems.

2. AT&T was required to license the Unix operating system's source code to anyone who asked.
   - AT&T full form: American Telephone and Telegraph Company.
   - AT&T was a telecom company. They had a legal agreement with the US government (antitrust deal) that restricted them to only the telecom business they weren't allowed to sell software as a commercial product.
   - So whenever a university or organization asked for Unix's source code, AT&T was legally forced to give it to them, usually for free or very cheap, because they couldn't compete in the software business.
   - This is why universities (like Berkeley) could freely study, modify, and build their own versions of Unix (like BSD Unix).
   - The word "required" means AT&T was forced by law to do this, not doing it by choice.

3. In 1984, AT&T divested itself of Bell Labs — Bell Labs began selling Unix as a proprietary product.
   - In 1984, AT&T split apart, and this legal restriction was lifted.
   - Bell Labs then turned Unix into a closed, paid, commercial product instead of freely sharing it.

**Why this matters:** Once Unix became closed and paid, people who wanted a free, open alternative couldn't get one easily anymore. This gap is exactly what pushed Linus Torvalds to create Linux later, as a free and open-source Unix-like system for everyone.

## GNU PROJECT
- Goal: create a "complete Unix-compatible software system" made entirely of free software
- 1985: Richard Stallman started the Free Software Foundation (FSF)
- 1989: Stallman wrote the GNU General Public License (GNU GPL)
- By early 1990s, GNU had built most needed programs (libraries, compilers, text editors, command-line shell, windowing system) — but no kernel yet

## MINIX
- Created in 1987 by Andrew S. Tanenbaum
- A minimal Unix-like OS made for students to learn OS principles
- Source code was freely viewable, but licensing terms didn't allow full "free software" freedoms
- Today, MINIX 3 is fully free and open-source

## LINUS TORVALDS
- 1991: while at University of Helsinki, Torvalds got curious about operating systems
- Built his own OS kernel, which became the Linux kernel
- Originally developed using MINIX and MINIX tools
- Later switched license to GNU GPL and adopted GNU Tools

### REVIEW
- Unix was owned and licensed by Bell Labs
- FSF created GNU tools as part of the GNU Project
- Linus Torvalds created the Linux kernel and used GNU Tools

## LINUX LICENSING MODEL

### GNU GPL
- GPL = General Public License
- Linux kernel + GNU Project code are licensed under GNU GPL
- You may freely copy, change, and distribute it
- You may NOT impose restrictions on further distribution
- You must make the source code available

### How companies make money on Linux
- Some distributions charge for a supported release
- Consultants charge for installation and customization
- Cloud companies don't distribute Linux itself, so they don't need to share source code. They provide services while using linux for their own. They don't share their modified source code which they are using.

### Competing with Microsoft
- Many commercial companies (IBM, Hewlett-Packard, Dell) gave up their own OS work and started using Linux to compete with Windows.

### REVIEW
- Open source does not mean you cannot charge for Linux
- If you give someone your changed Linux executable, you must give the source code too
- Everyone has the right to change and add to Linux

## LINUX DISTRIBUTIONS

### Red Hat Enterprise Linux (RHEL)
- Developed by Red Hat for the commercial market
- Price includes support
- Initial release: February 22, 2000
- Today, Red Hat is a subsidiary of IBM
- Server versions for x86-64, Power, ARM64, IBM Z; desktop version for x86-64
- Designed to be stable, with long-term support for enterprise users
- CentOS is a redistribution of RHEL with Red Hat's IP stripped out

### Fedora Linux
- Developed by the community-supported Fedora Project
- Sponsored primarily by Red Hat
- Initial release: November 6, 2003
- Over 30 releases so far
- Focuses on innovation by integrating new technologies early

### SUSE
- German-based multinational open-source software company
- Distributes: SUSE Linux Enterprise Server (SLES), openSUSE, SUSE Linux Enterprise Desktop
- Initial release: September 2, 1992
- Owned by Novell from 2003–2011

### Ubuntu
- Based on Debian
- Free to download; paid support available
- Three editions: Desktop, Server, and Core (for IoT devices and robots)
- Long Term Support (LTS) releases: supported for 5 years, released every 2 years

### REVIEW
- There are hundreds of Linux distributions
- Some require money to download, others are free
- All are open source, but they may include content that isn't open source
